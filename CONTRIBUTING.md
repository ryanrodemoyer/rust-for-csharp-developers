# Contributing to "Rust for C# Developers"

Thank you for your interest in contributing! Our mission is to make this repository the definitive, number-one resource on the internet for C# and .NET developers transitioning to or working with Rust.

## How Can You Contribute?

1. **Add High-Quality Resources:**
   - Found or published an insightful article, conference presentation, cheatsheet, or video tutorial?
   - Add it under the appropriate section in `README.md`.
   - Please include a 1–2 sentence description highlighting specifically why it is valuable to a C# or .NET developer.

2. **Add Comparison Topics & Examples:**
   - Expand the Rosetta Stone tables (e.g., additional LINQ methods, threading primitives, serialization idioms, or async patterns).
   - Add clear side-by-side C# and Rust code snippets.

3. **Improve FFI & Interoperability Guidance:**
   - Help document practical interop solutions (P/Invoke, `csbindgen`, NativeAOT, C-ABI best practices).

## Guidelines

- **Focus on C# / .NET context:** Resources and code samples should explicitly address the mental models and idioms familiar to C# programmers.
- **Maintain Markdown standards:** Ensure links are valid, formatting is clean, and code blocks specify their language tags (`csharp`, `rust`).
- **Be respectful and constructive:** Follow standard open-source community codes of conduct.
